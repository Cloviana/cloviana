### Current VAT Reconciliation Process

- Process starts from accounting system (COVIS)
  - Each bank product has dedicated accounting account
  - IVA charges recorded by product and region
- Compare accounting data against system reports
  - Reports subdivided by regions (Region 1000 = Misiones, Region 3000 = Salta, etc.)
  - Access macro compares totals by region first
  - Second macro analyzes differences by branch office
  - Final step: transaction-by-transaction analysis for largest differences
- Monthly process timing
  - Reports available 5-6 business days into month
  - Analysis must complete by day 19 for day 20 payment deadline
  - 7-10 working days available for full analysis

### Data Sources and Volume Challenges

- Accounting data (COVIS system)
  - Comes partitioned by region due to volume constraints
  - 5 days of Region 3000 data = 10,300 records
  - Region 5000 generates 20,000+ records per day
  - System limit of 15,000 lines for manual downloads
- System reports
  - Core banking system generates TXT files via batch process
  - Files deposited in shared server folders
  - Operations team requests report execution, available next morning
- Current workaround: Systems team provides monthly accounting extract to avoid manual downloads

### Pain Points and Manual Work

- File consolidation and volume management
  - Multiple TXT files require format conversion for Access macros
  - Excel limitations (1,048,576 row maximum)
- Format parsing for macro compatibility
  - Manual adjustment required to match Access format requirements
- Difference analysis process
  - Only analyze branches with largest differences (represents \~80-90% of total variance)
  - Manual investigation of each significant variance
  - 6-7 hours monthly for cartera and cuenta corriente products only
- Risk exposure
  - 10% of differences remain unanalyzed due to time constraints
  - Potential consequences: tax penalties, interest charges, client complaints

### Variance Analysis (Month-to-Month)

- Compares débito fiscal between consecutive months
  - Example: January 100M vs February 150M = 50M increase to investigate
- Process flow
  1. Identify products with largest month-over-month changes
  2. Drill down to branches showing biggest variances
  3. Analyze individual transactions within those branches
- Access macro compares current vs previous month system reports
- Manual investigation required to explain significant variances
  - Prevents “pink elephant” scenarios (unexplained 100% increases/decreases)
  - Ensures business changes have valid explanations
