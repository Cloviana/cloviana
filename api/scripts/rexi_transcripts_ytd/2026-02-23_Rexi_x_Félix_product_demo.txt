### Félix Current Reconciliation Challenges

- Operating multiple payment rails with limited visibility on pay-ins
  - Payouts mostly reconciled, but pay-ins rely on provider trust
  - Compare balances only - proceed if no drastic differences
- Blind spots in transaction traceability
  - Difficult to trace bounce-backs from SPEI or failed flows
  - Hard to identify which provider to contact when issues arise
  - Money location tracking problematic
- Manual balance-level reconciliation becoming painful at current volume (\~30k transactions/day)
  - Investigating differences requires deep-dive into balance comparisons
  - Need transactional-level matching vs balance comparison

### Previous Evaluation & Technical Requirements

- Evaluated Symmetric in 2023
  - Concluded too much heavy lifting required for data formatting
  - Preferred internal solution for “last mile” reconciliation
- Current provider landscape
  - Bitso and Arcus as main payment providers
  - Frequently onboard new providers (many not technologically advanced)
  - Often receive CSV files via email rather than APIs
- Security requirements
  - Need SOC 2 compliance (Rexi confirmed SOC 2 Type 2)
  - Prefer read-only credentials for provider access
  - Option for hashed data processing if needed
