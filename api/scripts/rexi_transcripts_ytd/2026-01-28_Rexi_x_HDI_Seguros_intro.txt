  - Ingests from multiple sources, standardizes to unified format
  - Automated matching with business rules and tolerance ranges
  - Problem solver module for discrepancy investigation
- Processing capabilities
  - 10-15 million records in 10-20 seconds
  - Batch processing (1-3x daily, not real-time)
  - No-code configuration for non-technical users
- Three deployment models available
  1. SaaS (cloud-hosted)
  2. Hybrid (customer-owned infrastructure, Rexi-operated)
  3. On-premise license (customer owns and operates code)
- Pricing varies by model: fixed, hybrid, or variable based on transaction volume
