SUMMARY

### Air Conciliation Process Overview

-   Current structure covers 3 largest countries: Brazil, Argentina, Mexico
-   Two main data sources:
    -   BSP (IATA): Standardized weekly extracts, well-organized for conciliation
    -   Low cost airlines: Direct partnerships, more varied/non-standardized data
-   Major pain points: Azul (PDF-only reports), TAM processing complexity
-   Rexi confirmed PDF reading capability now available

### Data Processing & Mapping

-   Raw extracts processed through internal Despegar application
-   Mapping transforms crude data to standardized format for all extracts
-   BSP mapping is standard across airlines
-   Low cost airlines require individual mapping configurations
-   Current volume: ~2M rows across all countries/processes
-   Oracle ERP generates intermediate tables for conciliation matching

### Conciliation Logic & Structure

-   Key matching fields:
    1.  Document number (ticket/reservation/PNR)
    2.  Airline code
    3.  Document type (sales vs post-sales: refunds, changes)
-   Concept-level reconciliation beyond total ticket cost:
    -   Base cost (cash amount)
    -   Standard commission
    -   Over-commission
    -   Taxes/penalties
-   IATA extracts: One line per ticket with concepts in columns
-   Oracle OM tables: Multiple lines per ticket with concepts in rows (205+ item types)

### Technical Implementation Considerations

-   Despegar undergoing data transformation - current structure may change
-   Need dynamic ingestion capability for format changes
-   Rexi maintains original data integrity with transformation trails
-   Database access with customizable role permissions available
-   Mapping documentation to be provided for automation within Rexi

### Non-Air (VCC) Conciliation

-   Virtual Credit Card payment method for tourism providers
-   Three bank partners: Itaú, Citi, WEX
-   Daily SFTP feeds with previous day’s consumption data
-   Core data points: reservation number, provider, charged amount, charge date
-   Oracle ERP integration for accounts payable matching
-   Format variations between banks but consistent core information

-   Share intermediate ERP-generated files for replication in Rexi
-   Obtain technical mapping details for Azul and TAM processing
-   Deliver VCC mapping specifications for non-air conciliation
