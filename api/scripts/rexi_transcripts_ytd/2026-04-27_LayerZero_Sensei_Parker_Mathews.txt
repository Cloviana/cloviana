### LayerZero Value Transfer Solutions

- Core specialty: facilitating value transfer between chains
- Current offerings:
  - OFTs (Omnichain Fungible Tokens) on Stargate
  - Hydra: LayerZero’s native stablecoins deployable on any chain
  - Stargate pools: lock/unlock mechanism via LayerZero messaging
- Intent-based solutions expanding rapidly
  - SWAPS framework with Aori as initial provider
  - 3 additional providers onboarding for specialized verticals
  - Focus on stablecoin orchestration and smart contract interactions
- Value Transfer API (closed beta)
  - No-code interface for neobanks/exchanges without solidity teams
  - Auto-indexes new OFT pathways upon deployment
  - Powers custom bridge frontends, deposits/withdrawals

### Zero L1 Launch Details

- Mainnet launch: Q4 2026, public testnet summer 2026
- Parallelized execution environments called “zones”:
  1. General Purpose Zone: EVM/Solidity environment for easy porting
  2. Capital Markets Zone: Rust VM optimized for trading
    - 2M TPS, 10ms latency (20x better than Hyperliquid)
    - Verifiable Apps (VAPs) framework compiles any language to validator-compatible code
- Validator requirements:
  - Ultra-lightweight hardware (Raspberry Pi capable)
  - Demo: 150 Pi validators processed 30 days of Ethereum transactions in 24 seconds
  - Can run on phones, Apple Watch, MacBook
  - No $50K servers required
- Validator selection process still being determined
  - Team of 150 (130 engineers), small business function
  - Parker will update on validator opportunities
