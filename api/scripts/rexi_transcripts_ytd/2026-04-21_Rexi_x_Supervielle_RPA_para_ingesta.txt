SUMMARY
============================================================
### RPA Implementation Overview

- Kevin Papa and Lucas Serrenho from Supervielle operations/IT hybrid team
- Goal: Automate file downloads from various systems (Van Total, Dynamics, Sislea) to eliminate manual processes
- Current state: Users manually download files and upload to Rexi platform
- Target: RPA bots download files automatically to SFTP for Rexi ingestion

### Technical Architecture Discussion

- Rexi’s preferred approach: SFTP connection with IP whitelisting
  - Standard method used with other clients
  - Rexi connects with read-only permissions
  - Automatic ingestion when new files appear
- Supervielle constraints:
  - Security approval process minimum 10 days
  - Separate permissions needed for each system (Van Total, Dynamics, Sislea)
  - Three different permission requests required for five total processes

### Process Scope & Complexity

- Five processes across three teams: two processes each for two teams, one for third team
- Each team has segregated permissions despite same management
- Systems involved:
  1. Van Total (multiple instances)
  2. Dynamics
  3. Sislea
- Recommendation: Start with simplest process for end-to-end testing before scaling

### Platform Capabilities & Change Management

- Rexi platform runs on AWS cloud
- Data quality monitoring detects schema changes automatically
- When file structure changes:
  - System flags warning and stops ingestion
  - Human intervention required to approve schema updates
  - Users can make changes directly in user-friendly interface
- Platform handles millions of records (vs Excel’s 200k limit)

- Kevin will coordinate directly with teams to identify simplest starting process

- Current constraints: Supervielle team reduced by 3 people, some on vacation
