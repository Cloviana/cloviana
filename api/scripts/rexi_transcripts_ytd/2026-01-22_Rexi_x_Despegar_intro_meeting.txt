- Serves financial services companies, insurers, payment processors, banks, crypto exchanges, digital wallets
- Two business models:

  2. On-premise deployment in client infrastructure
- Current clients include:
  - US neobank with 14M daily transactions (OnePay/Walmart wallet)
  - Beat (US), Taquenos, Callea (crypto wallets)
  - Pomelo, Banco Supervielle (starting)

### AI Integration Points

- Dynamic integration engine creates ad-hoc connectors for new data sources
  - Agent goes online, pulls APIs, configures, tests, finds bugs, iterates
- Automated data parsing interprets different file formats and nomenclatures
  - Identifies correct columns (amount, ID, cross-references)
  - Enriches data with third-party sources when needed
- Enhanced matching logic suggests new reconciliation keys
  - Improves matching ratios from 95% to 99.9%
- Discrepancy resolution module finds additional patterns
  - System learns from human actions and suggests rule codification
  - Automates exceptions (e.g., recurring manual transactions every Tuesday 5pm)

### Technical & Security Requirements

- SOC 2 Type 2 certified (recently obtained)
- Can work with hashed data for sensitive information
- Real-time processing not available - configurable batch processing (25-40x daily possible)
- Supports one-to-one, one-to-many, and many-to-many reconciliation
- Multi-currency support with configurable reporting columns
- Platform available in English only (translation possible if required)
