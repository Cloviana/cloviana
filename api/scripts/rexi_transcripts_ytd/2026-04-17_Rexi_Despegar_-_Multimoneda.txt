### Multi-Currency Implementation Requirements

- Three key features needed for Despegar integration:
  1. Extract information from SFTP file names and parse into columns
    - Serves both Yessica’s requirements and period tracking needs
    - Same feature implementation covers multiple use cases

    - Rexi will analyze integration and implement accordingly
  3. Conditional currency comparison feature

### Flight Payment Reconciliation Challenges

- Web platform lacks currency/amount breakdown that other channels have
  - Only shows single amount next to OMI
  - Majority of reconciliation cases work fine with existing setup
  - No tolerance settings - all differences get adjusted
- Complex scenario: Provider pays in USD, customer billed in ARS
  - ERP creates separate reconciliation document for internal purposes
  - Converts customer document from ARS to USD for provider reconciliation
  - Current workaround functional but not ideal
- Long-term goal: Normalize to contract currency
  - Would eliminate current reconciliation issues
  - Requires broader project coordination across teams

### Technical Implementation Details

- Currency conversion capability needed for reconciliation
  - Transform documents to required currency when conciliation keys match but currencies differ
  - Same document number, perfect reconciliation except for currency mismatch
- Exchange rate provider selection critical
  - Must have open APIs for easy implementation
  - Rexi has experience with multiple providers from other clients
  - Despegar needs to specify preferred converter
