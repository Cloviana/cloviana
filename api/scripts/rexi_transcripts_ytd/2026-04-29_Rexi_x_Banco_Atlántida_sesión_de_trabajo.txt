### Banco Atlántida’s Current Reconciliation Process

- Managing 9 remittance companies through SIREMU (Sistema de Remesas Múltiples) account
  - Includes Dolex, Intermex, Viaméricas and others
  - Separate accounts for MoneyGram, RIA, AirPak
- Daily reconciliation challenges:
  - 20,000-30,000 remittances per day debiting control account
  - Different closing times between remittance processor (8:30 PM) and SAP system
  - Creates “after-hours” or “nocturnal” transactions requiring manual reconciliation
- Current manual process using Excel macros:
  - Cross-reference DM report (SAP debits) with Base report (accounting closures)
  - Identify mismatched transactions, duplicates, manual credits
  - Track after-hours remittances for next-day compensation
  - Completely manual investigation for exceptions

### Technical Implementation Details

- Two primary data sources:
  - DM report: One-to-one debit transactions from SAP
  - Base report: Accounting closure data from remittance system
- Matching logic: Reference number (remittance ID) + amount
- Daily balance reconciliation process:
  1. Extract after-hours remittances (8:30 PM - 11:59 PM)
  2. Compensate previous day’s after-hours with current day credits
  3. Identify new after-hours for next day compensation
  4. Manual investigation of remaining exceptions
- Pain points: Overtime costs, data uncertainty, manual processes
