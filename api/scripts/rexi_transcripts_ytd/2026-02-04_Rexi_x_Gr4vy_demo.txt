### Rexi Platform Demo

- Automates FinOps processes: ingestion, standardization, reconciliation, report generation
- Demonstrated [checkout.com](http://checkout.com) settlement report transformation
  - Takes raw merchant data from checkout APIs
  - Maps to Gravy’s settlement report template using AI prompts
  - Generates standardized reports automatically
- Report creation process:
  - Upload CSV template or build manually
  - AI suggests column mappings with confidence scores
  - Custom formulas for complex transformations (e.g., “when client reference is not null, result is 1”)
  - Preview functionality before deployment
- Trigger options: source updates, scheduled (daily/weekly), or manual
- Output delivery: SFTP, API, or webhooks for notifications

### Technical Integration Architecture

- One source per merchant per PSP for atomic data organization
- Template-based approach with tags for report standardization
  - All [checkout.com](http://checkout.com) merchants use same template
  - Updates to template automatically apply to all tagged sources
- API credential management:
  - Gravy provides merchant credentials to Rexi via API
  - No separate merchant login required
  - Maintains better customer experience
- Data security: obfuscated data processing, only structure mapping visible
- Optional field handling: prompts return null/empty when data unavailable

### Gravy’s Current Reconciliation Challenges

- 80% of customers cannot use reconciliation module due to missing PSP integrations
- Long tail PSP connector development bottleneck
- Data parsing complexity becomes tribal knowledge (Masih as subject matter expert)
- 24-hour polling mechanism for settlement reports
- Manual credential setup for optional fields (action ID, etc.)
