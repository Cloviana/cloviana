SUMMARY

### One618 Operations Overview

- Securities operations focus with significant manual processes
  - Currently using Excel macros for most workflows
  - Exploring automation with Claude, APIs, Python, ChatGPT
  - Process still requires manual data ingestion - described as “tedious”
- Daily reconciliation requirements across multiple systems
  - Securities flow through market/bank custody systems
  - Cash flows through banking systems
  - Balance sheet closure required daily
  - Fund valuations published daily

### Current System Architecture & Pain Points

- Multiple data sources requiring reconciliation
  - Various APIs with different credentials
  - Banking systems with rigid security protocols
  - Several “canned” systems without direct API access
  - Direct database access needed for some integrations
- Primary systems used across industry
  - Primarily and Escofondos as standard platforms
  - 70% of fund managers use similar setups
  - Limited flexibility due to market infrastructure dependencies

### Rexi Integration Capabilities

- Data ingestion approaches
  1. API integrations (preferred path)
  2. Direct database connections
  3. Email-based data extraction
  4. Portal automation as last resort
- Dynamic integrator reduces setup time to 2-3 days
- AWS cloud infrastructure (US East 2)
  - SOC 2 compliant
  - Tenant-based data organization
  - Encrypted credential storage
- Licensing model available for on-premise deployment

### Market Experience & Positioning

- Current Argentina integrations
  - Working with Byma, Supervielle, Brubank
  - Starting engagement with Despegar
  - Various reconciliation types: cards, flights, insurance
- Limited experience with fund managers (ALICs)
  - Byma integration just beginning
  - No prior ALIC or fund management company experience
  - Banking integrations focused on non-capital markets areas

### Next Steps

- Demo scheduled to showcase platform flexibility
- Pilot program proposed at no cost
- Focus areas for evaluation
  - Banking reconciliation pain points for back office
  - Daily transfer operations through committee accounts
  - Bank of Values processes (highest volume area)
