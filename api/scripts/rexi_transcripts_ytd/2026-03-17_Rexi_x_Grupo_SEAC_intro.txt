### Company Overview - Grupo SEAC

- Payment services provider (PSP) in Argentina with PCP license
- 4 million transactions per month processing
- \~1,500 active merchant clients using wallet services
- Focus exclusively on merchant payment solutions (no end-user wallets)
- Company structure:
  - Legal entity: ReSimple Sociedad Anónima
  - Product branding: “ReSimple” (virtual wallet), “SEAC Pagos” (payment methods)
  - Website: [https://seac.com.ar](https://seac.com.ar)
  - Three separate legal entities operating under ReSimple umbrella
- Payment flow options for merchants:
  1. Credit card
  2. Debit card
  3. QR codes
  4. Bank transfers
- Merchant wallet allows setting custom payment timing (immediate, 2 days, 10 days, etc.)
- Backend processing through Payway, SmartPOS operations via SUGA

### Current Reconciliation Process & Pain Points

- Three-way reconciliation system:
  - Internal ledger (ReSimple) vs SUGA processing data
  - SUGA vs Payway settlement data (“liquidadas”)
  - Final validation against actual bank deposits
- Technical infrastructure:
  - Internal ledger provider: “Keep It Simple” (partner company)
  - Database: PostgreSQL with SQL Server replica
  - Custom reconciliation system built by internal programmers
- Manual processes creating friction:
  - File uploads via FTP from multiple sources
  - Balance-level reconciliation (not transaction-by-transaction)
  - Different identifiers across systems complicating transaction matching
- Dedicated reconciliation team:
  - 2 full-time staff members
  - Daily reconciliation target (sometimes extends beyond same day)
  - Manual investigation required when differences found
- Common reconciliation issues:
  - SUGA processing failures requiring transaction resubmission
  - Payway chargebacks affecting settlement amounts
  - Human errors in manual processes
  - Discovery delays (issues found day after occurrence)
